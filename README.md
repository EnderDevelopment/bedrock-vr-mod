# Bedrock VR Mod

Enhance your Minecraft Bedrock Edition experience with VR support for Android devices.

## Features

- Split-screen stereoscopic display for VR
- First-person perspective with head tracking
- Customizable VR settings including render scale and FOV
- Commands and keybinds for toggling VR mode and accessing settings
- Performance optimizations for mobile devices

## Requirements

- Minecraft Bedrock Edition 1.21.4
- Forge 49.0.2 or later
- Android device with a basic VR headset

## Installation

1. Download the mod from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft and enable the mod in the mods menu.

## Usage

### Commands

| Command     | Description                     |
|-------------|---------------------------------|
| `/vrmode`   | Toggle VR mode on/off.          |
| `/vrsettings` | Open the VR settings screen.    |

### Keybinds

| Keybind | Description                     |
|---------|---------------------------------|
| `V`     | Toggle VR mode on/off.          |
| `B`     | Open the VR settings screen.    |

### Items

| Item          | Description                     |
|---------------|---------------------------------|
| VR Toggle     | Toggle VR mode on/off.          |
| VR Settings   | Open the VR settings screen.    |

## Configuration

The mod includes a settings screen accessible via the `/vrsettings` command or the VR Settings item. You can adjust the following settings:

- Render Scale: Adjust the resolution of the VR display.
- FOV: Adjust the field of view for the VR display.
